# 在 VS Code 中运行

这是完整项目源码。解压后双击 `Folio.code-workspace`，或在 VS Code 中选择“文件 → 打开文件夹”并打开本目录。

## 1 安装依赖

先安装 Node.js 22.12 或以上版本，在 VS Code 终端中运行：

```bash
npm ci
```

## 2 创建 Supabase 数据库

1. 注册或登录 Supabase，创建一个免费的新项目。
2. 打开项目的 SQL Editor。
3. 将 `supabase/schema.sql` 的全部内容粘贴进去并执行一次。
4. 在 Authentication 的设置中启用 Anonymous sign-ins，也就是匿名登录。
5. 在项目设置中找到 Project URL 和公开的 anon key。

不要使用 service role key 或任何 secret key。数据库脚本用于全新项目，不要在已有同名表的项目里重复执行。

## 3 填写配置

把根目录的 `.env.example` 复制一份并命名为 `.env.local`。填入你刚刚找到的两个值：

```env
VITE_SUPABASE_URL=https://你的项目编号.supabase.co
VITE_SUPABASE_ANON_KEY=你的公开anon密钥
```

## 4 启动

```bash
npm run dev
```

打开终端显示的 Local 地址。真实看板一开始为空，点击 New task 创建任务。刷新后内容仍会保留。

如果暂时没有 Supabase，打开网页后点击 Explore a sample board，可以先查看界面。这个模式有明确的预览提示，不能保存、更改或拖动任务，不能作为最终上线演示提交。

## 5 使用

- New task：创建任务。
- 点击任务标题：编辑标题、描述、状态、优先级、截止日期、成员和标签。
- 拖动卡片右上角的六点手柄：跨列移动任务；也可直接修改任务详情中的 Status。
- 键盘操作：Tab 选中拖动手柄，空格拿起，方向键移动，空格放下，Esc 取消。
- Team members：添加成员名称和头像颜色。这是当前个人看板里的负责人列表，不会发送邀请。
- YOUR LABELS 旁的加号：创建标签。
- 任务详情的 Comments：添加评论。
- 任务详情的 Activity：查看自动保存的变更记录。
- 搜索框和筛选项：组合查询任务。

当前访客身份保存在当前浏览器中。清理浏览器数据、换浏览器或使用新的无痕窗口会进入另一个独立看板，不能用来找回原看板。

## 6 检查

```bash
npm test
npm run build
```

填好 Supabase 配置后，还可以执行：

```bash
npm run test:live
```

这项检查会创建两个匿名测试用户，验证真实云端连接和权限，并清理测试任务。匿名用户记录保留在 Supabase Authentication 中，可自行清理。未配置 Supabase 时不能运行这项云端检查。

## 7 上线和最终提交

详细操作见 `docs/DEPLOYMENT.md`。推荐把代码上传到 GitHub，再用 Vercel 免费部署。部署平台需要填写同样的两个环境变量。

`docs/firstname_lastname_task_manager_assessment.docx` 是可直接编辑的英文 Word 提交稿，包含完整 SQL；`docs/SUBMISSION.md` 是相同内容的 Markdown 版本。上线后在 Word 稿中补上姓名、网站链接和 GitHub 链接，导出 PDF 或直接保存为 DOCX。文件名改成你的 `firstname_lastname_task_manager_assessment.pdf` 或 `.docx`。按题目要求上传到 Google Drive，再把分享链接填入 Google Form。

最终交付文档不能保留占位字段；当前源码包也不代表已经完成真实账号配置或部署。不要把原题 PDF 放进 GitHub，不要公开发布最终提交文档的分享链接。
